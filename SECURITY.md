# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas de vulnérabilité ou de donnée sensible dans une issue publique.
Contactez les mainteneurs du projet directement avec une description, les
étapes de reproduction et une proposition de correction.

## Bonnes pratiques

- Utilisez un mot de passe long, unique et conservé dans un gestionnaire de mots de passe.
- Ne stockez jamais le mot de passe ou une clé Fernet dans le dépôt.
- Le sel présent dans le texte chiffré n'est pas secret.
- Ce projet protège les messages en mémoire et ne remplace pas un audit de sécurité professionnel.
